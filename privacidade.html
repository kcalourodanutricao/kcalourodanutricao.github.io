Política de Privacidade

Última atualização: 9 de novembro de 2026

Esta política vale para o canal Kcalouro da Nutrição (YouTube, Instagram e TikTok: @kcalourodanutricao) e para o Kcalouro Postador, a ferramenta interna que o canal usa para publicar os próprios vídeos.

1. O que é o Kcalouro Postador

É um programa de uso exclusivo do dono do canal, que roda no computador dele. Ele serve apenas para enviar e agendar os vídeos do Kcalouro da Nutrição nas contas do próprio canal (YouTube e outras redes). Não é oferecido ao público e não atende outros usuários.

2. Quais dados são acessados

Com a autorização do dono do canal, o programa acessa a conta do YouTube do Kcalouro da Nutrição para:

  • enviar vídeos (permissão youtube.upload);
  • ler as informações básicas do canal e a situação dos vídeos enviados, para confirmar que a publicação deu certo (permissão youtube.readonly).

O programa não acessa dados de espectadores, inscritos ou de qualquer outra pessoa.

3. Como os dados são guardados

As chaves de acesso (tokens de autorização) ficam salvas apenas no computador do dono do canal. Nenhum dado é enviado a servidores próprios ou de terceiros, além das próprias plataformas (Google/YouTube, Meta, TikTok) no momento da publicação.

4. Compartilhamento e venda

Nenhum dado é vendido, compartilhado, usado para publicidade ou para treinar modelos de inteligência artificial.

5. Serviços de API do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. O programa usa os Serviços de API do YouTube; ao usá-lo, valem os Termos de Serviço do YouTube e a Política de Privacidade do Google.

6. Como revogar o acesso

O acesso pode ser removido a qualquer momento em myaccount.google.com/permissions. Ao revogar, os tokens guardados no computador deixam de funcionar e podem ser apagados.

7. Quem visita o canal ou este site

Este site é estático: não usa cookies, formulários nem ferramentas de rastreamento. Nas redes sociais, os dados de quem assiste aos vídeos são tratados pelas próprias plataformas, conforme as políticas delas.
